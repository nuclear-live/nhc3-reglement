# NHC #3 · Apocalypse

Règlement officiel de la Nuclear Haunted Cup #3.

## Version refonte visuelle

Cette version conserve la structure GitHub Pages / Jekyll existante (`just-the-docs`) et ajoute une interface Apocalypse plus poussée :

- accueil type affiche de tournoi ;
- hub du règlement en cartes ;
- FAQ en accordéons ;
- galerie participants ;
- encadrés et cartes de score ;
- navigation et fond retravaillés ;
- responsive mobile.

Le `baseurl` reste `/nhc3-reglement`. Pour un test sur un dépôt d'un autre nom, modifier `baseurl` dans `_config.yml` afin qu'il corresponde exactement au nom du dépôt GitHub Pages.

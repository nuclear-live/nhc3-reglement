# Outils utiles

Plusieurs outils peuvent faciliter la préparation ou le suivi d'une partie pendant la Nuclear Haunted Cup #3.

Seuls les outils conformes au règlement sont autorisés pendant les parties.

## Calculateur de points

Le calculateur officiel du tournoi permet de faciliter le suivi du score.

Il est également accessible depuis la page **Calcul des points** du règlement.

[Lien vers le calculateur à ajouter]

## Trackers et outils Phasmophobia

Certains outils externes permettent de consulter des informations générales sur Phasmophobia, comme :

- les caractéristiques des différentes entités ;
- les cartes ;
- les emplacements possibles de certains éléments ;
- certaines mécaniques générales du jeu.

L'utilisation d'un outil ne doit cependant jamais fournir un avantage interdit par le règlement.

Les overlays interactifs avec le chat, les shaders et les outils modifiant artificiellement la visibilité restent notamment interdits.

## Guide anti-backseat

Un guide de configuration StreamElements est disponible afin d'aider les participants à mettre en place les mots interdits nécessaires pendant le tournoi.

Le guide complet est disponible dans la page **Règles concernant le chat**.
